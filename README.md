Desafío – Consultas Agrupadas (SQL)

Este proyecto corresponde a un desafío de SQL donde se aplican consultas agrupadas sobre un set de datos de inscripciones a cursos de inglés.
El dataset contiene la cantidad de inscritos por fecha y por fuente (Blog o Página).

El objetivo es practicar el uso de funciones de agregación, subconsultas, GROUP BY y HAVING para responder preguntas de negocio.


Archivos del repositorio

schema.sql → creación de la tabla INSCRITOS e inserción de los datos entregados.

consultas.sql → contiene las 10 consultas del desafío, con sus respectivas soluciones.

README.md → descripción del proyecto.
